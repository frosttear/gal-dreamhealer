# 梦境诊疗师 · 第一章

根据守拙《梦境诊疗师》第一卷编号 1 改编的 Web 视觉小说原型。第一章原文从附件的编号 1 提取到编号 2 之前，保存在仓库根目录。

## 运行

在项目根目录运行 `python3 -m http.server 8000 --directory dist`，打开 <http://localhost:8000>。也可以直接在浏览器中打开 `dist/index.html`。无需安装依赖或启动应用后端。

从主界面开始或继续游戏，也可以读取手动存档和查看图鉴。点击「继续」或使用空格、回车、右方向键推进。图鉴随剧情解锁，回顾记录本轮剧情。

主界面初始显示「血红之梦」，读到画面 6 后换为「扬城疑案」，读到画面 13 后换为「舒颜咖啡」。封面记录曾经到达的最远剧情，重玩或读取较早的存档时保留已解锁的封面。自动续读、手动存档、封面和图鉴进度保存在当前浏览器。

## 全稿制作估算

当前附件包含第一卷编号 1–12，共约 4.8 万个非空白字符。按第一章 4,301 字符改编为 16 个画面的密度，整份现有稿件约为 178 个画面。一个画面指一次可推进的叙事节拍，可以复用背景和立绘。以主线为主，预算可定为 160–210 个画面。若加入更多独立的调查操作、梦境变化和回忆镜头，则按 210–260 个画面估算。这个预算按当前附件计算。

| 素材 | 估算 | 说明 |
| --- | --- | --- |
| 基础人物立绘 | 12–16 张，已完成 7 张 | 优先覆盖苏禹、颜歆、沈义、余家姐妹、薛淼、迟欢及案情相关人物。只在档案或回忆出现的人物可先做单张。 |
| 表情变体 | 18–28 个 | 主要人物各增加 3–4 个常用表情。共用身体和服装，优先覆盖警觉、惊恐、质疑、放松等明显变化。 |
| 姿态变体 | 5–9 个 | 仅在叙事动作需要时新增整身或半身姿态，例如沈义蹲下问话、颜歆整理线索和苏禹使用连接器。 |
| 背景 | 14–20 张 | 同地点的梦境和现实可复用构图，再用灯光、色调或局部细节区别。 |
| 关键剧情插画 | 8–12 张 | 用于梦境转场、追逐、记忆揭示等构图变化明显的场面。 |

立绘预算合计约 35–53 个可调用版本，其中约 17–25 张需要独立身体或姿态。人物图鉴用常态版本。余筱玲与余雨的表现要兼顾身份悬念，图鉴随剧情更新，表情优先表现当下反应。

## TyranoScript 对照版

使用官方 TyranoScript V6.02c 在本地跑同一组 16 个画面、3 张背景和 6 张上场立绘。对照版使用引擎的剧本标签推进，两处合流选项简化为普通推进。

在项目根目录运行：

```sh
python3 scripts/build-tyrano-preview.py
python3 -m http.server 8000
```

打开 <http://localhost:8000/.tyrano-preview/> 运行预加载组，打开 <http://localhost:8000/.tyrano-preview/?preload=0> 关闭显式预加载。原生版地址为 <http://localhost:8000/dist/>。构建脚本从官方下载固定版本并校验 SHA-256。根据 SDK 随包条款，下载后的引擎和生成目录保存在本机。

### 加载实测

无头 Chromium 159，1280×800，每次用新浏览器上下文，每组运行三次取中位数。测试服务器为每次未缓存的 WebP 请求额外等待 250 ms。切换耗时从点击开始计到新文本、图片资源就绪并等待两帧。原生版首段包含从标题页进入游戏，与引擎对照版的首段耗时分开解读。

| 测量点 | TyranoScript 显式预加载 | TyranoScript 默认行为 | 原生 Demo |
| --- | ---: | ---: | ---: |
| 首段就绪 | 921 ms | 2,100 ms | 890 ms |
| 切到老小区，画面 6 | 111 ms | 303 ms | 307 ms |
| 切到咖啡店，画面 13 | 110 ms | 295 ms | 295 ms |
| 初见余筱玲立绘，画面 5 | 143 ms | 144 ms | 47 ms |
| 换成白羽立绘，画面 7 | 111 ms | 116 ms | 38 ms |

V6.02c 的 `chara_new` 会加载默认立绘。关闭显式预加载时，六张立绘在首段出现前串行请求，后两张背景各自在切换时才发请求。加上异步 `preload` 后，浏览器在开场就开始请求这一组素材。引擎的图片预加载等待 `load` 事件，测试版本的相关路径没有显式调用 `img.decode()`。

引擎提供 `chara_face`、`chara_mod`、`chara_move` 等演出标签。全稿若采用 TyranoScript，可按当前和下一场景分批预加载背景、立绘和表情。现有 Demo 也可以复用相同的背景预加载策略。

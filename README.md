# 梦境诊疗师 · 第一章

根据守拙《梦境诊疗师》第一卷编号 1 改编的 Web 视觉小说原型。第一章原文从附件的编号 1 提取到编号 2 之前，保存在仓库根目录。

## 运行

在项目根目录运行 `python3 -m http.server 8000 --directory dist`，打开 <http://localhost:8000>。也可以直接在浏览器中打开 `dist/index.html`。无需安装依赖或启动应用后端。

点击「继续」或使用空格、回车、右方向键推进。图鉴随剧情解锁，回顾记录本轮剧情。存档、读档和图鉴进度保存在当前浏览器。

## 改编结构

| 画面 | 视角与地点 | 主要情节 |
| --- | --- | --- |
| 1–5 | 余筱玲 · 卧室 | 模糊的时钟、血红天空、红裙女人和惊醒后的异样 |
| 6–12 | 沈义 · 扬城老小区 | 黑裙女尸、薛淼报警、余筱玲求助和小姨缺失的小指 |
| 13–16 | 颜歆与苏禹 · 舒颜咖啡 | 求助帖串起时间线，介绍入梦刑侦，以七十万委托收尾 |

两个互动选项汇入原作主线。剧本与图鉴由 `dist/story.js` 管理，界面和本地进度由原生 HTML、CSS、JavaScript 实现。人物立绘和场景由内置 ImageGen 生成，裁切为独立 WebP 素材。

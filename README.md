# 梦境诊疗师

根据守拙《梦境诊疗师》第一卷改编的 Web 视觉小说原型。现有原稿包含 12 章，Demo 已适配第 1–3 章。第一章原文保存在仓库根目录。

## 运行

在项目根目录运行：

```sh
python3 scripts/build-tyrano.py
python3 -m http.server 8000 --directory dist
```

打开 <http://localhost:8000>。构建脚本从官方下载 TyranoScript V6.02c 并校验 SHA-256。也可用 `--archive` 指定已下载的官方压缩包。根据 SDK 随包条款，引擎只解包到本机的 `dist/engine/`。

从主界面开始、自动续读、读取手动存档或打开图鉴。台词逐字显示。显示过程中点击可补全当前文字，读完后再点击推进。TyranoScript 管理剧本、选项、立绘、背景、回顾、自动存档和手动存档。图鉴和封面进度保存在当前浏览器。旧原生版的图鉴和封面记录会沿用，旧版剧情存档和 TyranoScript 存档使用不同格式。

主界面初始显示「血红之梦」，读到画面 6 后换为「扬城疑案」，读到画面 13 后换为「舒颜咖啡」。封面记录曾经到达的最远剧情，重玩或读取较早的存档时保留已解锁的封面。Demo 使用第一章的章内节点，后续正式版可以按大章节解锁。咖啡店名写在第三张封面的门头招牌上。

## GitHub Pages

[在线游玩](https://frosttear.github.io/gal-dreamhealer/dist/)使用仓库的 Pages 工作流部署。工作流在发布前构建 TyranoScript，并将整个 `dist/` 作为游戏目录上传。仓库的 Pages 发布源需设为 **GitHub Actions**。

## 改编结构

| 章节 | 主线画面 | 剧情 |
| --- | ---: | --- |
| 第一章 | 16 | 余筱玲的血红噩梦，扬城老小区的黑裙命案，舒颜咖啡接下七十万委托 |
| 第二章 | 13 | 扬城警察局的两份笔录，余筱玲的梦中证词，以及「蒸汽时代」六号包间的见面 |
| 第三章 | 15 | 福利院雨夜旧档、三桩案件的交集、左腕印记和警方可能发出的匿名委托 |

第一章两处选项仍汇入同一画面。第二章的笔录可追问异常声响或新住户，第三章的雨夜档案可先查看门边的白伞或湖边的哭声。两处选项都有独立画面和图鉴线索，并改变第三章后段苏禹的研判。每轮阅读有 44 个主线画面加 2 个分支画面，主线案件仍会继续推进。

用 `tyrano-game/scenario/chapter1.ks` 至 `chapter3.ks` 编辑剧本和演出，用 `dist/catalog.js` 编辑图鉴。引擎按章异步预加载。第 2、3 章新增了迟欢、陈清、秦桥的立绘、薛淼的笔录造型，以及 6 张场景。素材由内置 ImageGen 生成，裁切为独立 WebP。

## 人物美术

已完成 11 张基础立绘，以及薛淼的笔录造型、余筱玲的冷静警惕表情和颜歆的熟人见面微笑，共 14 张可用素材。图鉴仍用常态立绘，表情和服装变体在对应剧情里调用。李护工在第三章雨夜回忆中登场，同时解锁图鉴立绘。

| 人物 | 原作依据与画面处理 |
| --- | --- |
| 李护工 | 全稿写到他夜巡逐间确认孩子睡下、清点雨伞，并在害怕时仍追查哭声。朴素工作服和手电体现护工身份。年龄和面貌为改编设定。 |
| 余筱玲 | 开场受到惊吓，警戒线外主动求助，随后有一瞬冷意。保留同一张脸、发夹和校服，用眼神区分这组情绪。 |
| 颜歆 | 粉白卫衣和侧马尾来自原著。与熟人相处时活泼，在入梦与分析线索时更专注，微笑版和常态版沿用同一服装及轮廓。 |
| 薛淼 | 案发现场有遮眼刘海和宽松蓝衣。到警局后梳开刘海、换成干练常服，两种造型保留同一脸型和偏瘦体态。 |
| 苏禹、沈义 | 苏禹保留黑风衣及思索时的克制神情。沈义保留胡茬与便衣，后续可用更温和的表情表现他面对孩子时的耐心。 |

## 全稿制作估算

当前附件包含第一卷编号 1–12，共约 4.8 万个非空白字符。按第一章 4,301 字符改编为 16 个画面的密度，整份现有稿件约为 178 个画面。一个画面指一次可推进的叙事节拍，可以复用背景和立绘。以主线为主，预算可定为 160–210 个画面。若加入更多独立的调查操作、梦境变化和回忆镜头，则按 210–260 个画面估算。这个预算按当前附件计算。

| 素材 | 估算 | 说明 |
| --- | --- | --- |
| 基础人物立绘 | 12–16 张，已完成 11 张 | 优先覆盖苏禹、颜歆、沈义、余家姐妹、薛淼、迟欢及案情相关人物。只在档案或回忆出现的人物可先做单张。 |
| 表情变体 | 18–28 个 | 主要人物各增加 3–4 个常用表情。共用身体和服装，优先覆盖警觉、惊恐、质疑、放松等明显变化。 |
| 姿态变体 | 5–9 个 | 仅在叙事动作需要时新增整身或半身姿态，例如沈义蹲下问话、颜歆整理线索和苏禹使用连接器。 |
| 背景 | 14–20 张 | 同地点的梦境和现实可复用构图，再用灯光、色调或局部细节区别。 |
| 关键剧情插画 | 8–12 张 | 用于梦境转场、追逐、记忆揭示等构图变化明显的场面。 |

立绘预算合计约 35–53 个可调用版本，其中约 17–25 张需要独立身体或姿态。人物图鉴用常态版本。余筱玲与余雨的表现要兼顾身份悬念，图鉴随剧情更新，表情优先表现当下反应。
